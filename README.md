# Retos en Nivel

Mod de Geode para Geometry Dash Android. Al entrar a un nivel muestra un reto aleatorio; al completar el nivel o abandonar un intento, informa el resultado una sola vez.

## Compatibilidad

- Geometry Dash Android 2.2091
- Geode oficial v6.0.0
- Android ARM64 / Android64
- ID del mod: `jolaf.retosenivel`
- Versión del mod: 1.2.4

## Compilación

El flujo **Build Android64** de GitHub Actions compila el mod con la versión de SDK indicada en `mod.json` y publica el archivo `.geode` como artefacto descargable de la ejecución. También puedes compilar localmente con Geode CLI v6.0.0 y el Android NDK instalado.
