# Retos en Nivel

Mod de Geode para Geometry Dash Android 2.2081.

Al entrar a un nivel muestra un reto aleatorio mediante una notificación de Geode.

## Compatibilidad

- Geometry Dash Android 2.2081
- Geode 5.10.1
- Android ARM64 / android64

## Descarga

[Descargar el archivo .geode](https://github.com/jolafgdps-art/retos-en-nivel/raw/main/releases/retos-en-nivel-android-2.2081-jolaf.geode)

## Compilación

Necesitas Geode SDK 5.10.1, bindings de Geometry Dash 2.2081 y Android NDK.
